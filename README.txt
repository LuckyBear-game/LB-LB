Lucky Bear — автономная локальная версия

Откройте файл index.html двойным кликом в браузере.

Структура:
- index.html — главная страница
- */index.html — отдельные страницы разделов
- site.css — общий стиль
- site.js — мобильное меню и FAQ
- assets/ — локальные изображения
- sitemap.xml и robots.txt — SEO-файлы

Сборка, Node.js, React, Vite и сервер не требуются.
Кнопки регистрации и игры ведут на https://lucky-bear.lb-game.ru/site.
